项目名称：400米配速计算器
作者：Philip
目标：输入400米目标成绩，输出每100米建议分段。
功能列表：

输入400米目标成绩

输出每100米建议分段

输出前后200米建议

保存历史记录

如何运行：
    需要 Python

    运行命令：python src/main.py

示例输出：
    please type your ideal record of 400m:51
    your ideal record:51.0

    recommend:
    第一个100米：12.25
    第二个100米：12.05
    第三个100米:13.05
    第四个100米:13.65

    继续输入成绩，还是输入q退出？
    q
